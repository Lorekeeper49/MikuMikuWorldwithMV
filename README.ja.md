# MikuMikuWorld
プロセカ用の譜面エディタ・譜面ビューアー。

このフォークは、元の MikuMikuWorld が失われる前に crash5band によってコードを取得していることに注意してください。

## 必要な環境：
- 64bitのWindows 10以上¹
- [Microsoft Visual C++再頒布可能](https://aka.ms/vs/17/release/vc_redist.x64.exe)
- GPU対応のOpenGL 3.3と最新のドライバ

1：古いバージョンでも動くかもしれませんが、動作確認はされていません。

## 機能一覧：
- Sliding Universal Score（\*.sus）ファイルの入出力。
- BPM・拍子・ハイスピーの調整。
- 最大1920分音符までのカスタム分割。
- ノーツプリセットの作成・使用。
- カスタマイズ可能なキーボードショートカット。

## 追加機能：
- **MV対応**：MV（MP4、MKV、WebM、MOV、AVIなど一般的な形式）を独自のオフセット付きで読み込めます。MVは無音で再生され、タイムラインとプレビューの背景を置き換え、スクロールや再生の位置に合わせて表示されます。動画の長さの範囲外では通常の背景が表示されます。動画のデコードには同梱のFFmpegライブラリを使用します。
- **字幕**：字幕ファイル（\*.srt、\*.vtt、\*.ass、\*.ssa）を読み込み、タイムラインとプレビューに歌詞を表示できます。タイミングは音源のオフセットに合わせられます。表示位置は設定から下・上（横書き）、左・右（縦書き）を選べます。
- **ゲームに準拠したクレジット**：アーティスト欄が「作詞」「作曲」「編曲」「ボーカル」の個別の欄になりました。SUSの`#ARTIST`にはゲームと同じ形式（`作詞：… 作曲：… 編曲：… Vo. …`）で出力され、インポート時に読み込まれます。旧バージョンで保存した譜面は、可能な範囲でアーティスト欄の文字列が各欄に分けられます。
- **統計の追加**：統計の表にスキル発動とFEVER CHANCEの数も表示されます。
- MVファイル、MVオフセット、字幕ファイルは\*.mmws譜面ファイルに保存されます。
